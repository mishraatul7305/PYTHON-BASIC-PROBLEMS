# PYTHON-BASIC-PROBLEMS
Python beginner practice programs covering loops, break, continue, conditional statements, type casting, dictionaries, and basic problem-solving.
 # Python Basic Problems 🐍

This repository contains my Python programming practice problems as I learn Python fundamentals and improve my problem-solving skills.

## 📚 Topics Covered

* **Break Statement:** Stop a loop when a condition is met.
* **Continue Statement:** Skip a particular iteration.
* **Even or Odd:** Check whether a number is even or odd.
* **Largest of Three Numbers:** Find the largest number using conditional statements.
* **Loops:** Print numbers using `for` loops and `range()`.
* **Print Statements:** Understand output formatting.
* **Type Casting:** Convert strings into integers and floating-point numbers.
* **Dictionaries:** Store and display data using Python dictionaries.
